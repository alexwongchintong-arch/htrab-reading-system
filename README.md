# 读书笔记 · 阅读系统

依据《如何阅读一本书》（艾德勒 & 范多伦，郝明义 / 朱衣 译，商务印书馆）搭建的个人阅读笔记系统。当前主线是 `05-阅读系统`：一个**单文件网页应用**——双击 `index.html` 即可使用，无需联网、无需安装。一本书从「记下书名」开始，沿 **检视 → 主动 → 分析** 逐层沉淀骨架、疑问、判断与收获。

> 说明：原书全文与扫描版因版权原因**不包含**在本仓库中，系统的步骤设计请以原书为准对照参考。

```
05-阅读系统/index.html   阅读系统（单文件网页应用，双击即用）        ← 当前主线
05-阅读系统/DESIGN.md    界面设计规范（布局 / 配色 / 组件）
05-阅读系统/_build/      生成器：template-jianshi.html（模板）+ products.mjs（步骤配置）+ build.mjs
05-阅读系统/_demos/      设计过程稿（demo-e 藏书架 = 已落地的首页原型）
01-检视阅读 … 04-主题阅读  早期的四个独立小工具（存档，见文末）
```

## 阅读层次的定位

系统按原书的层次递进组织。每个层次的**职责边界**如下（这是本系统的核心设计约定）：

| 层次 | 定位 | 做什么 | 不做什么 |
|---|---|---|---|
| **检视阅读** | 书籍的**基础信息 + 基础阅读** | 书名页/序言/出版者（第一印象）、目录页（**全书大纲升级版**：勾出轮廓，关注完整性与先后顺序）、翻内文（词目与篇章）。记下书名即占位，随时可以开始 | 不做深度分析——目录页只搭骨架，细读留给后面 |
| **主动阅读** | 检视与分析之间的**简易过渡层（可选）** | 四个基本问题（整体 → 细部 → 判断 → 与我何干），用最小步子的提问，鼓励完成第一遍完整笔记 | 不承担深读职责——**可以完全跳过**，其内容被分析阅读覆盖 |
| **分析阅读** | **深化阅读**（精读） | 15 条规则、三个阶段：① 结构（分类/一句话/本书框架/作者的问题）② 诠释（术语共识/关键句主旨/论述/找出解答）③ 评论（礼节自检/四个批评标准）。三个阶段均已落地 | — |
| **主题阅读** | **多书对话**（最高层次，已落地） | 围绕一个议题读多本书：阅览室创建议题并选书 → 议题工作台五步（章节地图 / 中立词汇 / 问题序列 / 界定议题 / 分析讨论）→ 汇总导出辩证笔记 | 不强迫重新检视阅读——书只是材料，议题才是主角 |

### 双路线（重要）

完成检视阅读（任一轮阅读进度到 100%）后，同一本书解锁**两条并行路线**：

```
             ┌─ 路线 a：主动阅读（简易过渡，可做可不做）
检视阅读 ────┤
             └─ 路线 b：直接进入分析阅读（跳过主动阅读）
```

- 两条路线互不阻塞：做了主动阅读随时可以进分析阅读；跳过主动阅读也能直接做分析阅读。
- **确认走分析阅读的书，不再经过主动阅读**——包括返回键：做过四问的，返回目标是主动阅读；直接进入的，返回目标是检视阅读。
- 主动阅读相当于「小步子」的鼓励机制（参考意义），分析阅读才是完整的深化流程。

## 首页 · 书单工作台（藏书架形态）

首页是一面**藏书架**：木框书柜、丝带书签（绿=检视 / 橙=主动 / 蓝=分析）、书脊脚下标注阶段与进度。

- **书架形态**：每层可以放很多书——从下往上填，底行放满、溢出的书进上一层（行间有薄木隔板），书多时层的空间自动向上生长。
- **常见操作**：
  - 拖动书脊：调整顺序，可跨层、可跨行；拖动层标/层空白：整层换序；
  - 每层末尾的**虚线书**：向该层添加图书；层名可改（✎）、整层可删（✕，书入整理推车）；
  - **跳转书架**（下拉）：聚焦某一层书架（再次选「全部书架」还原）；
  - **整理推车**：下架的书暂存在这里，拖回任意层即可重新上架；
  - **归档**（按钮带数量）：进入归档室，回看暂停阅读的书。
- 顶部统计：`藏书 N 册 · N 册在读 · 书架 N 层`（不含归档书）。

## 归档室

书籍页顶栏的**「归档」**取代了删除：任一阶段读不下去、暂不值得读的书，都可以按下暂停——

- 归档时要填一段**暂时不再阅读的理由**（会显示在归档室，是以后重启这本书的线索）；
- 归档后书从**书架、阅览室与本季清单**移出，笔记全部留存、转入归档室；
- 归档室列出：书名/作者、**开始阅读**（最早一轮的起始日期）与**归档日期**、理由；
  点卡片可**只读回看**该书已记录的笔记（检视/主动/分析三段完整呈现，不可编辑）；
- 想继续时点**「放回 → 整理推车」**：书回到整理推车，再由你决定放回哪一层书架（需重新加入本季清单）。

## 单书页面

左中右三栏：**流程栏**（本层次的步骤导航）｜**表单卡**（当前步骤）｜**回顾栏**（前序层次的记录，默认只读、可切换编辑）。

- **检视阅读一（3 步）**：① 书名页与出版者的介绍（含类型粗判[可多选]、宗旨、角度、同类书、推荐人）② 目录页：全书框架（阅读路径 / 目录写法 / 全书的主题 / 议题范围）③ 翻内文：词目与篇章（重要词目、篇章卡、最后两三页、提到的书）。
- **检视阅读二**：**阅读轮次**（多轮，一体化进度滑杆，拖到 100% 即读完；结束日期可随时补）＋ **疑问问答**（跨轮汇总，任何一轮可答任何一轮的疑问，永久可追溯）。
- **主动阅读**：四问笔记本（问题三、四带行内表态与行动清单）。
- **分析阅读 · 阶段一（结构，规则 1-4）**：分类（附分类测试）→ 一句话 → 本书框架（主题+主旨为内核，从属议题挂要点）→ 作者的问题（要问的 / 要解决的）。
- **分析阅读 · 阶段二（诠释，规则 5-8）**：术语共识（一词一卡）→ 关键句主旨（一句一卡：位置+摘录，卡名即主旨复述）→ 论述（一卡一主旨，论据按先后+论证关系；可从主旨建卡）→ 找出解答（联动规则四的问题清单逐条评定）。
- **分析阅读 · 阶段三（评论，规则 9-15）**：礼节自检（规则 9-11 选择题 + 各记一句当前判断，可一键翻速查卡）→ 批评标准（规则 12-15 只做判断；判「有此问题」的标准在左缘多出便签，进详情页逐条写证据）→ 整体评论与收获（收尾一步；结论由评定自动推导：同意/不同意/暂缓评论）。
- **状态链**：未开始 → 检视一·进行中 → 待通读 → 检视二·第 N 轮 x% → 检视二 100%（通读完成、尚未深读）→ 主动阅读·进行中/完成 → 分析阅读·进行中。

## 共同功能

- **阅读清单**：按年·季度规划书单——书目、起始/结束日期、进度滑杆；统计「平均读完一本（X 天）/ 本季书目 / 已读完」。与轮次数据双向同步（单一数据源）。
- **主题阅读（议题）**：首页或阅览室点「议题」创建议题 → 阅览室选书模式里点书砖选书、点金色状态牌看该书笔记 → 议题工作台（摊开的书，绛红主题）做五个步骤，问题清单自动流入「界定议题 / 分析讨论」→ 汇总页一键复制 / 下载辩证笔记 `.md`。议题书目存快照，书被删后议题不塌。
- **速查卡 / 分类助手**：原书方法速查（阅读速度三招、两个子层次、作者的问题公式等）；两三个点选判断书籍类型（虚构/论说 → 理论/实用 → 历史/科学/哲学）。
- **导出**：书页右上角「导出笔记」一键复制 / 下载 `.md`。
- **自动保存**：所有内容实时存入浏览器 localStorage，随时关闭随时续写。

## 数据与维护

- 数据保存在浏览器本地（localStorage，键均为 `hrab_pipe_` 前缀：`books` / `plans` / `shelves` / `topics`〔议题〕/ `types` / `ui` / `bgtheme` / `seed` / `import` 等）。**不同地址、不同浏览器各自独立**，重要数据请及时导出。
- 数据带版本戳（当前 `ver 16`），旧数据加载时自动迁移（如：类型单值→多值、纲要 note→items、书架扁平列表→行结构、全书主干→主题+主旨、论述理由序列→论据）。
- **修改步骤/文案**：编辑 `_build/products.mjs`（步骤与字段）或 `_build/template-jianshi.html`（界面逻辑与样式），然后运行：

  ```bash
  node _build/build.mjs
  ```

  会生成 `05-阅读系统/index.html`。
- 界面设计规范见 `05-阅读系统/DESIGN.md`。

## 设计原则

- **小步子**：一屏一事，每步只做一件小事、写一段大白话说明，假设使用者完全不了解原书。
- **MECE**：步骤互不重叠、合并不遗漏，严格对应原书的层次与规则；每步有独立命名的产物。
- **第一性原理**：每步明确「做什么」（写在步骤说明）、「不做什么」（由字段范围隐性约束）、「承上启下」（引用条带出前序成果、汇总导出自动拼装）。
- **每本书、每条内容都是多条的**：「每章 / 每条 / 每本书」维度的内容一律做成可增删的条目结构（动态清单、分组卡片、表格、行内标签），不用单一输入框。

## 早期工具（存档）

`01-检视阅读`、`02-主动阅读`、`03-分析阅读`、`04-主题阅读` 是 2026-09 期间做的四个**相互独立**的单文件工具（生成器在根目录 `_build/`）。它们保留作为参考，数据与当前阅读系统不互通；当前开发与使用以 `05-阅读系统` 为准。

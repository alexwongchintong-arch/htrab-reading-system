# 阅读系统 · 设计规范记录

> 以「主动阅读」页为基准样板，后续层次（分析阅读等）必须复用同一套布局与交互语言。

## 布局

- **检视阅读页**（`b.cur <= STEP_N+2`）：**摊开的书 · 只露右页**（`.layout.roll`）——按真实书本解剖还原：深绿布面**封面**包边（`.rollcover`，比书页大一圈，左/上/下缘露出 2–4mm）→ 书脊侧一薄摞**已读页摞**（`.rollread`，比未读侧略旧）→ **中缝折痕**（`.rollcrease` + 页面左缘弯进书脊的弧度阴影）→ 单页内容 → 右侧**未读页摞**（竖纹书口，`::before`）→ 底部页摞坐在封面上（`::after`）。步骤签是从已读页摞伸出的**索引纸签**（`.layout.roll .etab-l`：纸色竖排小签，当前签描边 + 层次色字，金点 = 已填，`data-go`）。页眉右侧放「→ 主动阅读 / → 分析阅读」下一阶段钮（未解锁时 `.mini.lk` 虚线灰显）。宽度 `min(1120px, calc(100% - 140px))` 居中；此视图的题名栏（`.topbar.bk.rollv`）与书同宽居中、副题缩进 58px 对齐页眉文字栏。**注意：装饰件必须是 `.layout.roll` 的直接子元素，不能放进 `.page-roll`（`overflow:hidden` 会裁掉）。**
- **主动 / 分析阅读页**（`b.cur >= STEP_N+3`）：**摊开的书**（`.layout.dual`，Demo H 移植）——
  - 左页 `.page-l` = 当前层次笔记表单（`#stage` 卡片去边框融入书页）；右页 `.page-r` = 回顾栏（`#review`，`.rcard` 去边框融入书页）。
  - 书本装饰：中缝凹陷（`.layout.dual::before`）、左右书口横纹页摞（`.bkedge`）、底部通宽页摞（`::after`）、左页丝带书签（`.ribbon`，层次色）。
  - 书随内容自然变高（`min-height: calc(100vh - 170px)`，`.sheet` 为 `flex:1 0 auto` 不内滚），左右页始终等高。
  - 书本模式下 `body.bookmode` 切换为桌面底色（深一档，衬托书页）；检视/主动/分析所有单书视图都是书本模式。
- **跨层导航**：左页页眉 `.phead-nav`（主动页 = ← 检视阅读 / 分析阅读 →；分析页 = ← 检视阅读常驻，做过四问的再加 ← 主动阅读）。
- **页眉标题区**（三个层次统一，2026-10-06 起）：`.runhead` = 层次大标题（22px 衬线加粗：检视阅读一/二、主动阅读、分析阅读）——不再拼接「四问笔记 / 阶段名 / 第 x / y 步 / 产物徽章」等冗余，当前位置由左缘步骤签与阶段胶囊承担，标题短了跨层钮也不会被挤换行；`.phead-desc` = 层次/阶段描述（检视 = 有系统的略读 / 粗浅的阅读；主动 = `part3.goal`；分析 = 当前阶段 `goal`），紧贴标题同区展示；`.phead-sub` = 进度注释行；分析页 `.stagetrack` 阶段胶囊排在描述之后。页眉横线只分隔「标题 + 注释」与「步骤问题」。
- ≤1100px 时书本竖排堆叠（`.page{flex:0 0 auto}`，必须有——列向 flex 里 `1 1 0` 会把页面压塌）：左右缘便签变横排、书口/中缝/卷脊隐藏。
- **首页书架 · 宽屏排布与书脊尺寸**（2026-10-07 定版）：
  - **书脊只显示书名 + 状态牌**（作者名不再上书脊——缩略后书名会与作者重叠，按用户要求移除；`.bk-au` 样式与 `bkNarrow()` 一并清理）。
  - **数量化排布规则**：`shFlat(sh).length` **< 20 本**的层按存储顺序**两两配对并排**——**中间隔多少个通铺层都不影响配对**（待配对层跨过通铺层继续等待，并排组输出在两者之间最后一个通铺层之后；`.bk-pair` 纵向 flex = 行区 `.bk-pairrow` + **共用贯通底板**）；半宽小书架恒为半屏尺寸 S=1，可分两层、`bkChunk(…, maxPerRow=10)` **每行最多 10 本**，虚线添加砖占末行；配不上对的奇数层与 **≥ 20 本**的层独占整行**通铺**（`bkScale(true)`：大屏适度放大书脊 `min(1.3, innerWidth/1400)`，减少整行留白），通铺仍放不下的维持**多行分层**。≥900px 才启用并排，窄屏与聚焦模式一律全宽。整层拖动会把存储顺序重写为所见顺序，配对随之收敛、不会抖动。
  - **左右书架之间有隔断板**：并排组行区中插 `.bk-divider`（12px 竖向木纹条，`align-self:stretch` 贯穿行高、落在贯通底板上沿），呈现双联书柜的实体感。
  - **长书名遮挡修复**：`bkMeasure()` 两段式求解——先按基础高度解字号（计入 `.bk-tt` 的 1.5px 字距，下限 9.5px），触底仍放不下则**加高书脊**（≤380px）再解一次；竖排书名不再溢出遮挡下方「检视阅读 / 100%」状态牌（全量 spine 零重叠）。
  - **拖拽命中加 X 轴**：并排后左右两层同高，书脊拖动的行命中加 `clientX ∈ [left−30, right+30]`，整层拖动改矩形包含 + 左右半区判定落点（纯 Y 判定会把落点窜到旁边的层）；`bkCommit` 仍按 unit 重建，跨层拖入并排组不受影响。
- **顶栏**：单书视图 = Demo H 题名栏（`.topbar.bk` 全宽 flex，两端对齐；检视单页书视图加 `.rollv` 与书同宽居中）：左侧大衬线书名《xx》+「作者 · 当前层次：xx」副题，右侧操作钮排在标题与书本之间（`.bktag` 烫金小签：← 书单 / 编辑信息 / 导出笔记 / 速查卡 / 删除〔红色 `.bktag.red`〕）。**长书名防错位（2026-10-06）**：顶栏为单行骨架 `flex-wrap:nowrap`，标题列 `.bkmast-t{flex:1 1 auto;min-width:0}` 可收缩、h1 `overflow-wrap:break-word` 在列内自然换行；按钮组 `.bkmast-ops{flex:0 0 auto;flex-wrap:nowrap}` 永不整块掉行（原 `flex-wrap:wrap` 会在书名过长时让按钮整组掉到左下错位，已弃）。≤640px 兜底：标题独占一行，按钮组 `flex:1 1 100%` 内部换行且右对齐、`.rollv` 放宽为 `calc(100% - 32px)`。副题统一缩进对齐下方页眉标题：摊书页 46px（= 左页 `.phead` 左 padding），折页书 58px（`.rollv` 覆写）。

- **书页最短高度跟着左缘便签**（2026-10-07 加，`fitBookToTabs()`）：两侧内容都短时（如议题「起点」「中立词汇」步）书页会缩得比左缘步骤签列还矮、便签伸出页底。现在每次 render / `rerenderStage` / `rerenderTopicStage` / 窗口 resize 后，量出最后一枚 `.etab-l` 的底边相对书页顶边的距离 + 26px 下留白，作为 `.layout.dual` / `.layout.roll` 的行内 `min-height`（不够高才设，够了就清掉交回 CSS 的 `calc(100vh - 170px)`），书页与页摞装饰一起被撑到能盖住整列便签。
- **拖拽实现要点（2026-10-07 起）**：整层拖动与书脊拖动都用「rAF 节流 + 落点去重」——每帧最多算一次落点，落点未变化时不碰 DOM（旧写法每次 pointermove 都 `insertBefore`，并排组被反复拆装 → 闪屏）。
  - 整层拖动以**顶层块**（`.bk-unit` / `.bk-pair`）为落点，按「第一个中线在指针之下的块」判定（不要把指针矩形包含判定限制在别的块内：指针落在被拖层自己的矩形里时会没有目标、跳到最后）；从并排组里起拖时先把该层拎成顶层独占，提交时 `render(true)` 会自动重新配对。
  - 提交（pointerup）按 `.bookcase > .bk-unit` 与 `.bk-pair` 内层的 DOM 顺序重建 `shelvesData`，筛选隐藏的层追加在后。

## 数据与状态
